# אתר "החקלאים באים" – יריד ראדא

האתר בנוי כדף יריד סטטי עם Decap CMS, כך שאפשר לערוך טקסטים, משקים, קישורים ותמונות דרך `/admin/` בלי לערוך קוד.

## מה כבר בפנים
- 8 משקים לפי הרשימה שסיפקת.
- שתי תמונות שהעלית: משק ביידר ושמן ברמה.
- קישורי ההזמנה שסיפקת.
- חלוקה ברורה בין מכירה במקום, הזמנה מראש עם ספיירים, והזמנה מראש בלבד.
- פרטי תאריך/שעות/מיקום מוגדרים כשדות לעריכה.

## פרסום
הדרך המומלצת היא GitHub + Netlify + Decap CMS. אחרי חיבור האתר ל-Git, כל שינוי ששומרים דרך `/admin/` נשמר בקוד ומפעיל פרסום חדש.

## חשוב
לפני פרסום סופי יש להשלים:
- תאריך היריד
- שעות היריד
- קישור הזמנה של שמן ברמה
- ואם יש: קישורי מידע נוספים למשקים
- תמונות נוספות למשקים
